# ML datasets

**Datasets are NOT committed to git.**

Raw and processed sensor/fault data can be large, may contain sensitive lab logs, and change frequently. Keep them local (or on shared team storage) and document paths/versions here when Layer 3 starts.

- Place raw dumps under this folder locally (ignored by `.gitignore` via `ml/data/*`).
- This `README.md` is tracked so the folder purpose stays visible.
- Record dataset provenance, labeling scheme, and split ratios in team docs or notebooks — not by committing the files.
